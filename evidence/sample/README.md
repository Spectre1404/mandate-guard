# Sample evidence packet

`evidence-packet.pdf` and `evidence-packet.json` were generated by a real end-to-end run of this
system — compiler, shopping agent, verification gate, Prava client, and a Playwright checkout against
the Beanline storefront — with `fake_prava` standing in for the Prava sandbox and a live `gpt-5-mini`
call producing the labelled narrative section.

Regenerate with:

```
.venv/bin/python scripts/make_sample_packet.py
```

> **This is the `fake_prava` version.** It will be replaced by a packet from a real Prava sandbox
> integration checkpoint, carrying a genuine `visa_confirmation`, which becomes the flagship sample.
